# Product

DRRS (Debt Restructure Registration System) เป็น Web Application สำหรับให้ลูกค้า
ลงทะเบียนและยื่นคำขอ "ปรับโครงสร้างหนี้" ด้วยตนเองผ่านหน้าเว็บ (self-service)
โปรเจกต์นี้ต่อยอดจากเทมเพลต Material Kit 2 React ของ Creative Tim

## กลุ่มผู้ใช้

- ลูกค้าทั่วไป (ประชาชน) ที่เข้ามากรอกข้อมูลและเลือกแผนปรับโครงสร้างหนี้
- UI เป็นภาษาไทยทั้งหมด ต้องรองรับฟอนต์ไทย (NotoSansThai, GSB)

## Flow หลักของผู้ใช้ (ตามลำดับหน้า)

1. `consent` — หน้ายินยอม (จุดเริ่ม เปิด session)
2. `form-register` — กรอกข้อมูลผู้ลงทะเบียน
3. `loan-plan` / `loan-plan-detail` — ดูข้อมูลสินเชื่อ
4. `select-plan` / `plan-preview` / `plan-summary` — เลือกและสรุปแผน
5. `gen-contract` — สร้าง/ดูสัญญา (PDF)

ทุกหน้าหลังจาก consent ถูกป้องกันด้วย `SessionGuard` (ต้องมี session ที่ถูกต้อง)

## หลักการที่ต้องรักษาเสมอ

- เป็นระบบของสถาบันการเงิน ข้อมูลลูกค้าเป็นข้อมูลอ่อนไหว ห้าม log ข้อมูลส่วนบุคคล
  (เลขบัตรประชาชน, ข้อมูลสินเชื่อ) ออกสู่ console ใน production
- ข้อความที่แสดงให้ผู้ใช้เห็นเป็นภาษาไทยเสมอ
- มี session timeout และจำกัดจำนวน tab เพื่อความปลอดภัย
